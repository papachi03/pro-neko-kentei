# ぷろ猫けんてい

猫に「食べさせてよい物」と「危険な物」を瞬時に見極める、スマートフォン向け縦画面Webゲームです。

## ゲームの目的

このゲームは単なる反射神経ゲームではありません。**猫を飼育するうえで自分がどれだけ正しい知識を持っているかを再確認し、危機管理能力を高め、愛猫の健康について考えるきっかけを作る**教育ゲームです。

- プレイ中はテンポよく判断して遊ぶ
- 学習は主に **失敗後・結果画面・図鑑** で行う
- プレイ結果は「八級〜八段」の16段階で認定される

> ⚠ **重要：現在の食品情報はすべて開発中の仮データです（獣医学的監修前）。**
> UI上にも仮データである旨のバナーを常時表示しています。正式リリース前に `js/foods.js` を信頼できる獣医学的情報源をもとに差し替えてください。

## 起動方法

サーバー不要の静的Webゲームです。

- ローカル確認：プロジェクトフォルダで簡易サーバーを起動してブラウザで開く
  ```
  python -m http.server 8123
  → http://localhost:8123
  ```
  （`file://` 直接オープンでも動作しますが、ブラウザによっては制限があるためサーバー経由を推奨）
- 公開：フォルダごと GitHub Pages / Netlify 等の静的ホスティングへアップロードするだけです

### GitHub Pages で公開する手順

1. GitHubにリポジトリを作成し、このフォルダの内容をpush
2. リポジトリの Settings → Pages → Branch を `main` / `(root)` に設定
3. 表示されたURL（`https://ユーザー名.github.io/リポジトリ名/`）にアクセス

## 操作方法

| 状況 | 操作 |
|---|---|
| 食べてもよい物が出た | **食べ物をタップ** → 猫がもぐもぐ食べる |
| 危険な物が出た | **猫の尻尾をタップ** → 尻尾で「バチコーン！」と弾き飛ばす |

- 間違えると LIFE が1減る（時間切れもミス扱い）
- LIFE×3 がなくなるとゲームオーバー → 検定結果へ
- 正解を続けると COMBO が伸び、スコア倍率が上がる
- 時間が経つほど出題テンポが速くなる

PCではマウスクリックで同様に遊べます（Pointer Eventsで共通化）。

│  ├─ foods.js         食品データ（仮データ）・難易度モード定義

## 現在実装されている機能

- タイトル画面・難易度選択（初級/中級/上級）
- 皿を差し出すアニメーション（画面下から手＋皿がスライドイン）
- 待機アニメーション（呼吸・尻尾の揺れ）
- 食べるアニメーション（反応→顔を近づける→もぐもぐ＋文字/ハートエフェクト＋食べ物が減る→満足）
- 尻尾攻撃アニメーション（予備動作→右から左へスイング→バチコーン！→食べ物が回転しながら左へ吹き飛ぶ→復帰）
- SCORE / COMBO / LIFE / PAUSE / 経過時間
- COMBO演出（ポンッと拡大、5/10/20/30…の節目バナー、段階的に豪華化、喪失時のガクッと落ちる演出）
- 時間経過による高速化（判断時間 3秒→1秒、下限あり）
- 出題ロジック（安全が続くと危険が出やすい・同一食品の連続防止）
- 誤入力防止（1皿1判定・アニメ中ロック・連打/二重発火対策）
- ゲームオーバー → 間違えた食品の解説（理由・予防・受診の促し）
- ねこ食事図鑑（未遭遇は？？？、結果画面から直接復習可能）
- 検定評価（正答率45%・難易度25%・SCORE20%・COMBO10%＋危険食品誤食ペナルティ）
- 八級〜八段の認定・昇級/昇段/八段の特別演出・次の階級までの進捗表示
- localStorage保存（ハイスコア・最高COMBO・最高正答率・最高段位・図鑑・履歴／破損時も起動可能）
- スマートフォン縦画面・PCマウス対応・レスポンシブ

## カスタマイズ方法

### 食品データの追加・差し替え

`js/foods.js` の `FOODS` 配列にオブジェクトを追加します。

```js
{
  id: "unique_id",          // 一意なID
  name: "表示名",
  category: "初級食材" | "料理" | "加工食品",   // 難易度モードの出題対象を決める
  safety: "safe" | "caution" | "danger",       // safe=食べる が正解、それ以外=弾く が正解
  difficulty: 1〜3,         // 基礎スコア倍率
  description: "説明",
  symptoms: "起こりうる影響",
  prevention: "家庭での予防",
  emergencyAdvice: "誤食時の対応（獣医師への相談を促す文面）",
  source: "情報源・監修元",
  image: "🍎",              // 現在は絵文字。画像パスへの差し替えも可
}
```

獣医学的監修が完了したら `foods.js` 冒頭の `FOOD_DATA_STATUS` を `"verified"` に変更してください（現状 `"placeholder"` の間はUIに仮データバナーが出ます ※バナー表示自体は現在ハードコードのため、正式版でこのフラグと連動させてください）。

### 猫画像・アニメーション素材の差し替え

- 正式デザインは `assets/cat/master/cat_master.png`。ゲーム内の猫は `assets/cat/parts/` の透過PNG（tail → body → head の3層）を重ね合わせて描画しています
- パーツ画像を差し替える場合は同名ファイルを置き換えるだけです。表情（head）を追加する場合は `js/animations.js` の `CAT_PARTS` と `HEAD_LAYOUT`（画像ごとの位置補正）に1行追加します
- パーツの配置・レイヤー順は `css/style.css` の「猫（PNGパーツ合成方式）」セクション（`#cat-head` `#cat-body` `#cat-tail`）で調整。尻尾攻撃中のみ `.attacking` で尻尾が最前面になります
- 手・皿は `index.html` の `.plate-hand-svg` を差し替え

### 食品画像の差し替え

`foods.js` の `image` を画像パスにし、`ui.js` / `animations.js` で `textContent` にしている箇所を `<img>` 挿入へ変更してください（`food-display` / 図鑑 / 結果画面の3箇所）。

### 効果音の追加

演出の発火点にフックがあります：`Anim._playImpact()`（バチコーン）、`Anim.updateCombo()`（正解）、`Anim.comboLost()`（ミス）、`UI._renderRankupBanner()`（昇級）など。ここに `new Audio(...)` 等を追加し、音源は `assets/sounds/` へ。

### 難易度・テンポの調整

`js/game.js` の `CONFIG`：

- `decisionTimeline` … 経過秒→判断時間(ms)の対応表（高速化カーブ）
- `gapAfterResolve` … 次の皿までの間隔
- `minSpeedScale` … アニメーション短縮の下限
- `maxLife` / `baseScore`

### COMBO倍率・演出の変更

- 倍率：`game.js` の `CONFIG.comboMultipliers`
- 節目・演出の段階：`animations.js` の `comboTierFor()` と `showComboMilestone()`、見た目は `style.css` の `.hud-combo.tier-*` / `.combo-banner.size-*`

### 検定評価ロジック・級位段位基準の変更

`js/ranks.js`：

- `RANK_WEIGHTS` … 正答率/難易度/SCORE/COMBOの重み
- `DANGER_FED_PENALTY` … 危険食品を食べさせたミス1回あたりの減点
- `RANK_THRESHOLDS` … 各階級の認定しきい値（総合スコア0-100）
- `RANKS` … 階級名・称号文言

## 現在仮実装になっている部分

- **食品情報の内容すべて**（獣医学的監修前の仮データ。`source` は未設定）
- 手・皿：SVG／食品：絵文字（正式イラストへの差し替え前提の構造。猫は正式PNGパーツ実装済み）
- ミス時の専用表情（head_miss）は未実装（現在は震え＋✕マークで表現）
- 効果音：未実装（フックのみ）
- ランキング：ローカル記録のみ（オンラインランキングは将来拡張）
- 「本試験モード」（固定問題数での正式検定）：未実装（`DIFFICULTY_MODES` と評価ロジックを流用して追加できる設計）
- 仮データバナーの表示は `FOOD_DATA_STATUS` フラグと未連動（現状常時表示）
