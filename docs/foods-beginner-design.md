## 0. 今回追加で確認した3点

### 0-1. 生イカ（squid_raw）の根拠再確認

より専門性の高い一次・専門資料を追加調査した。

- **Merck Veterinary Manual**（欧米の代表的な獣医学リファレンス）：
  チアミナーゼによるビタミンB1（チアミン）欠乏の機序自体は明確に記載。
  ただし名指しされているのは主に「生の淡水魚（freshwater fish）」「二枚貝（clams）」で、
  イカを個別に列挙してはいない。
- **JAVMA（米国獣医師会雑誌）／PMC掲載レビュー論文**：
  猫はビタミンB1要求量が犬の3倍で欠乏しやすいこと、生魚食がリスク要因であることを確認。
  同じくイカへの個別言及はなし。
- **学術文献（甲殻類・頭足類のチアミナーゼ含有に関する研究）**：
  頭足類（イカ・タコ）にチアミナーゼを含む種が存在することは確認できたが、
  「全種に共通ではなく種によって有無が分かれる」「研究自体が発展途上」という留保がある。
- **日本の獣医師監修記事（複数・独立）**：
  ねこのきもちWEB MAGAZINE、PS保険、ペットファミリー損保など、
  異なる運営元・異なる獣医師監修の記事が揃って「生イカ＝チアミナーゼ→ビタミンB1欠乏」
  という同一の説明をしており、日本の獣医療現場での説明としては広く一致している。

**判定：機序（一次資料）＋頭足類のチアミナーゼ含有（学術文献）＋日本の複数の独立した
獣医師監修記事の一致、という三重の裏付けにより、初級編候補として維持する。**
ただし「イカ＝チアミナーゼ確定」という単一の一次論文は確認できなかったため、
`sources` には資料の性質（マニュアル／学術文献／獣医師監修記事）を明記し、
将来より直接的な一次資料が見つかった場合に差し替えられるようにする。

### 0-2. feedingRecommendationの整理（safe食品の"主食"混同防止）

`risk: "safe"` の5食品はすべて安全に食べられるが、日常的に主食として与えるべきかは別問題。
以下のように明確に分離する。

| 食品 | risk | feedingRecommendation | 理由 |
|---|---|---|---|
| 猫用総合栄養食 | safe | **daily**（主食） | 栄養バランスが調整された唯一の主食候補 |
| 加熱鶏ささみ（味付けなし・骨なし） | safe | occasional（補助的） | 栄養が主食ほど調整されておらず、トッピング・ごほうび程度が適切 |
| 加熱鮭（味付けなし・骨なし） | safe | occasional（補助的） | 同上 |
| 猫用ミルク | safe | occasional（補助的） | 水分補給・嗜好品であり主食の代わりにはならない |
| 市販の猫用おやつ | safe | occasional（補助的） | パッケージの給与量目安を守る前提の"おやつ" |

`feedingRecommendation: "daily"` を持つのは初級編では猫用総合栄養食のみとし、
それ以外のsafe食品はゲーム中の短い解説文でも「食べられるが主食ではない」旨を明記する。

### 0-3. ハム・ソーセージの riskCategories 名称見直し

旧案の `sodium_additive` は「添加物＝毒」という誤解を招く恐れがあるため、
`human_food_seasoning` へ変更し、説明の重心を**塩分・人間向けの味付け**に置く。
添加物・保存料については「毒性がある」とは書かず、「猫の体格には想定されていない
味付け・加工がされている」という中立的な表現にとどめる。

- 変更前：`sodium_additive`（塩分・添加物過多）
- 変更後：`human_food_seasoning`（人間用の味付け・加工食品）
  説明例：「ハムやソーセージは人間の味覚に合わせて塩分や香辛料が使われており、
  猫の体格にとっては塩分の摂りすぎになりやすい食品です。添加物自体が毒という
  意味ではなく、"人間用に作られた食品＝猫向けではない"という考え方です。」

### 0-4. squid_raw（生イカ）の表現ルール（今回追加確定）

**squid_rawは`toxin`カテゴリの食品（玉ねぎ・チョコレート等）と同列に扱わない。**
両者は危険の性質が根本的に異なるため、ゲーム内のあらゆるテキストで以下を徹底する。

| 観点 | `toxin`（玉ねぎ・チョコ等） | `squid_raw`（生イカ） |
|---|---|---|
| 危険の性質 | 特定成分が直接的に中毒・臓器障害を起こす | 特定の栄養素（ビタミンB1）を壊す酵素の作用が、摂取が続くことで欠乏症につながる |
| 発症までの量・期間 | 少量・単発の誤食でも症状が出うる | **一口・少量の誤食では基本的に問題にならない**。大量または長期間の継続摂取で欠乏症状が出うる |
| ゲーム内`riskCategories` | `toxin` | `nutrient_deficiency`（据え置き。`toxin`は付与しない） |
| shortMessage（正解時の一言）で使ってよい表現 | 「中毒」「毒」「与えてはいけない」等、強い表現可 | 「ビタミンが壊れちゃう」「栄養が偏っちゃう」など、栄養バランスの話として説明。「毒」「中毒」の語は使わない |
| 避けるべき表現 | ― | 「少量でも中毒になる」「危険な毒がある」「食べたら病気になる」等、即時的な中毒であるかのような言い回し |
| 推奨する説明の骨子 | 「これを食べると中毒を起こします」 | 「生のイカにはビタミンB1を壊す酵素が含まれています。**一口食べてすぐ大きな問題になるわけではありませんが**、続けて食べさせるのはやめましょう。加熱すればこの酵素はなくなります」 |
| emergencyAdvice のトーン | 「すぐに動物病院へ」等、緊急性を強めに表現してよい | 「大量に食べてしまった場合や、体調の変化（元気がない・ふらつく等）が見られる場合は獣医師に相談してください」と、**冷静な条件付き表現**にする（誤って一口食べただけで慌てさせない） |

## A. 初級編の設計方針（変更なし）

初級編は「猫を飼うなら最低限知っておきたい食べ物の知識」に限定する。
判断基準は、①猫用食品か人間用食品か、②生か加熱済みか、③味付け・加工の有無、の3点。
量・体重・個体差・持病で結論が変わるものは採用しない。

## 1. caution比率の再検討：5個 vs 2〜3個

| 比較軸 | 案A: caution 5個（初回提案） | 案B: caution 2〜3個に絞る（推奨） |
|---|---|---|
| dangerとの混同リスク | **高い**。15食品中1/3がcautionだと「弾く＝危険」という単純な図式が強化され、caution特有の"条件次第"という意味合いが埋もれる | 低い。caution数が少数精鋭になるため、「これは特別なパターンだ」と意識させやすい |
| 学習内容の重複 | 牛乳・生卵・生イカ・ハム・骨付き肉と理由がバラバラで、1周のプレイでは覚えきれない | 理由のカテゴリが異なる3つに絞ることで、caution＝「毒ではないが注意が必要な複数パターンがある」と整理して学べる |
| 初見の分かりやすさ | 中（caution登場頻度が高く、判断に迷う場面が増える） | 高（caution登場頻度が適度で、safe/dangerの明確な判断に集中できる） |
| 難易度設計との整合性 | cautionが多すぎるとレベル1（明確なsafe/danger）の比率が下がる | レベル1中心の初級編にcautionを"香辛料"程度に混ぜられる |
| 教育的正確性 | 変わらず高い（分類自体は正しい） | 変わらず高い。個数を絞っても医学的分類は変更しない |

**結論：案B（caution 2〜3個）を採用する。**
初級編のcautionは以下の3個に絞る（理由カテゴリが重複しない3種を選定）。

- 牛乳（人間用）… 消化器症状・不耐性
- 生イカ … 加熱条件・栄養阻害（日本での認知度が高い代表例）
- ハム・ソーセージ（加工肉） … 塩分・加工食品

生卵・骨付き加熱鶏肉は次章の個別再評価により中級編へ移動する。

## 3. caution候補5個の個別再評価

| 食品 | 初級に残すか | 判定理由 |
|---|---|---|
| **牛乳（人間用）** | ✅ 初級に残す | 症状は消化器系（下痢）にとどまり、"猫=牛乳"という広く知られた誤解を正す教育価値が非常に高い。画像も「牛乳パック／コップに注がれた牛乳」で誤認の余地がほぼない。初級の最初のcautionとして最適 |
| **生卵（卵白）** | ➡️ **中級へ移動** | 機序（アビジン→ビオチン欠乏）に加えサルモネラ菌リスクも絡み、理由が二重で初心者にはやや複雑。さらに「生卵」と「加熱した卵（ゆで卵・スクランブルエッグ）」を画像だけで明確に区別するのが難しく、誤認防止の観点（本文書「画像仕様」参照の原則）で初級には不向き。中級編で"料理の中の卵"として再構成する |
| **生イカ** | ✅ 初級に残す | 「イカを食べると腰が抜ける」という日本で非常に有名な俗説を正しく理解できる教育価値が高い。生イカ（半透明・白っぽい）と加熱イカ（白く不透明・丸まった形状）は画像上の区別も比較的容易 |
| **ハム・ソーセージ（加工肉）** | ✅ 初級に残す | 「肉だから安全」という誤解を正す代表例。画像も一般的な加工肉の見た目で認識しやすく、誤認リスクが低い |
| **骨付き加熱鶏肉** | ➡️ **中級へ移動** | 危険理由が他のcaution（毒性・不耐性）と異なり「物理的損傷」という別カテゴリで、初級3枠に入れると理由の一貫性が崩れる。かつ#2の骨なし加熱鶏肉との違いが「骨の有無」という小さな差異のみで、小さいスマホ画面での誤認リスクが最も高い。骨を強調した構図を作り込む必要があり、中級編（料理・加工の判断）に置く方が適切 |

## 4. 危険理由カテゴリのデータ化案

`riskCategories` を配列で持たせ、1食品に複数該当してもよい設計とする。

| カテゴリID | 意味 | 該当食品（初級） |
|---|---|---|
| `toxin` | 特定成分による中毒 | 玉ねぎ・にんにく（有機チオ硫酸化合物）／チョコレート・カフェイン（メチルキサンチン）／アルコール（エタノール） |
| `nutrient_deficiency` | 栄養素の破壊・吸収阻害 | 生イカ（チアミナーゼによるビタミンB1破壊） |
| `digestive_upset` | 中毒ではなく消化器症状 | 牛乳（乳糖不耐症） |
| `human_food_seasoning`（旧`sodium_additive`から改称） | 人間用の味付け・加工食品（塩分中心。添加物＝毒という表現は使わない） | ハム・ソーセージ |
| `physical_injury` | 誤嚥・消化管損傷など物理的リスク | （中級へ移動）骨付き加熱鶏肉 |
| `food_safety_bacteria` | 生食による菌汚染リスク | （中級へ移動）生卵 |

データ例（`riskCategories: ["nutrient_deficiency"]`のように付与）。
図鑑や結果画面で「なぜダメなのか」をカテゴリ別アイコンで示す拡張にも使える
（例：🧪毒性 / 🍽消化器 / 🧂塩分 / 🦴物理的リスク）。今回はデータ保持のみ提案し、
UI実装は見送る。

※ `feedingRecommendation` は「daily（主食）／occasional（補助的・量に注意）／avoid（基本は避ける）／never（絶対NG）」の4段階。
　safe食品のうち**主食(daily)は猫用総合栄養食のみ**とし、他のsafe食品は"食べられるが主食ではない"ことを明示する（詳細は0-2章）。

**中級編への繰り越し候補（参考・今回は未確定）**：生卵（卵白）／骨付き加熱鶏肉／長ねぎ／生の鶏骨
